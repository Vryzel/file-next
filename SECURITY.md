# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability.

Use [private vulnerability reporting](../../security/advisories/new):

1. Open the Security tab.
2. Choose **Report a vulnerability**.
3. Describe the impact and how to reproduce it.

There is no separate security email. The private advisory is the only reporting channel.

## What happens next

We will acknowledge the report within 5 business days and aim to share a fix or mitigation plan within 30 days.

## Scope

This policy covers the code in this repository. Report vulnerabilities in dependencies to the upstream project.
