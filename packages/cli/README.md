# @vryzel/file-next-cli

CLI for file-next.

```bash
pnpm add -g @vryzel/file-next-cli
# or: pnpm dlx @vryzel/file-next-cli
file-next migrate --adapter=sqlite
file-next reconcile --tenant=<id> --dry-run
file-next doctor
```

Packages publish to GitHub Packages today. See [github-packages.md](../../docs/github-packages.md).
