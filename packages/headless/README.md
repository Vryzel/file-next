# @vryzel/file-next-headless

Headless React hooks for `@vryzel/file-next`. No UI, no Tailwind, no Radix. Server work is injected as callbacks.

```bash
pnpm add @vryzel/file-next-headless
```

| Hook | Role |
|---|---|
| `useFileBrowser` | List + loading/empty/error |
| `useFileExplorer` | View mode, selection, drag on top of the list |
| `useUploader` | XHR upload with progress and cancel |
| `useFileActions` | Optimistic delete/move/copy/rename |
| `useFileUrl` | Presigned download URL |
| `useDownloadProgress` | Fetch download with progress |

Packages publish to GitHub Packages today. See the repository README.
